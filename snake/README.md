# 赛博贪吃蛇 (Neon Cyberpunk Snake)

经典的贪吃蛇游戏，采用赛博朋克霓虹美学、Web Audio API 原生合成音效、变异道具系统与 A* 寻路 AI 对战模式。

## 🌟 核心特性 (Features)

1. **🎨 赛博霓虹视觉 (Cyberpunk Neon Canvas)**：
   - 动态发光渐变蛇身、蛇头方向瞳孔、能量食物粒子光爆动画。
2. **🍎 丰富变异食物 (Dynamic Food Items)**：
   - **能量晶核 (Apple)**: +100分，长度+1。
   - **黄金超载星 (Golden Star)**: +500分，限时超额奖励。
   - **疾风蓝核 (Speed Surge)**: +250分，极速充能。
   - **相位紫菌 (Phase Shifter)**: +300分，变异缩短蛇身。
3. **🎮 双模式对决 (Dual Modes)**：
   - **10级经典闯关 (Classic Campaign)**: 关卡递增速度曲线与激光路障挑战。
   - **人机双蛇对决 (Dual Snake Arena)**: A* 寻路 AI 实时争夺领地与食物。
4. **📱 全端自适应操作 (Responsive Controls)**：
   - PC: 键盘方向键 / WASD、Enter / Space 快捷开始。
   - 手机/平板: 屏幕滑动滑动手势 + 荧光虚拟方向键。

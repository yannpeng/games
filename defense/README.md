# 田园守卫战 (Wildwood Defenders)

一个采用经典与现代策略融合、全套田园与森林动物守卫阵营的 60 FPS HTML5 网页塔防游戏。

---

## 🐾 8 大动物守卫特性 (Defender Roster)

1. **🐓 雄鸡守卫 (Rooster)**：近程高频啄击 + 【晨曦破晓】光环（提升周围防御塔 25% 攻击速度）。
2. **🐔 母鸡队长 (Hen)**：投掷范围爆破鸡蛋 + 【金蛋丰收】（每 10 秒产出 10 金币后勤补给）。
3. **🐿️ 神枪松鼠 (Squirrel)**：树梢超远距离狙击 + 30% 暴击率与 2 体直线穿透。
4. **🦌 黑尾鹿尊 (Deer)**：地面重踏震波，对周围范围敌人施加 45% 群体减速。
5. **🦝 巧手浣熊 (Raccoon)**：投掷毒气炸弹造成 4 秒持续毒素伤害，被击败敌人掉落额外 25% 金币。
6. **🦅 苍穹猎鹰 (Eagle)**：全图自动索敌，对生命值低于 30% 的残血精英怪造成 3 倍斩杀。
7. **🦉 智者猫头鹰 (Owl)**：释放弹射 3 个目标的连锁奥术闪电 + 【真视之眼】识破隐身黄鼠狼。
8. **🐰 急速机枪兔 (Rabbit)**：双持胡萝卜机关枪进行极速弹幕压制。

---

## 🎮 游戏操作与特色机制 (Gameplay Controls)

- **点击部署**：在下方编队中选择动物守卫，点击草地网格进行放置（右键可取消部署）。
- **升星与回收**：点击场上的守卫可打开检视面板，执行 **⭐ 升星强化**（Lv.1 ~ Lv.3 👑）或 **💰 回收变现**。
- **指挥官技能 (Commander Skills)**：
  - 🥕 **胡萝卜暴雨**：全屏轰炸所有在场入侵者。
  - 🥚 **金蛋空投**：紧急获取 +150 金币经济补给。
  - ⚡ **动物狂暴**：8 秒内全员防御塔攻击速度翻倍。
- **游戏倍速**：支持 1X / 2X / 4X 变速调节与自动出波（Auto-Wave）。
